# 影子修理铺 / Shadow Workshop

2D 空间益智游戏。玩家移动、旋转桌面上的日常物件，调整台灯位置，让投在投影板上的影子重新拼成目标图形。

Godot 4.7.1 · GDScript · 竖屏 9:16 · 单机离线 · 无广告内购

> 设计基线与 18 关总体规划见上级目录的 `影子修理铺_立项与设计基线_v1.0.md`。

## 玩法

1. **看**目标轮廓（投影板上的浅色描边）
2. **拖**桌面上的物件，或直接拖它投出的影子
3. **转**选中物件后用「逆转 / 顺转」，每次 30°
4. **切**灯位（有多个预设时），灯位决定影子的大小和位置
5. **检查**，达到阈值即通过，按步数和精度给 1–3 星

桌面上：带淡橙圆环的物件可以拖；带方框标记的是固定件，拖不动。

## 判定机制

### 投影

从点光源把物件顶点投到投影平面，是**确定性 2D 几何投影**，不是真实的 3D 光照模拟。

```
Q = L + k · (P − L)        k = H / (H − h)

L  灯光位置 (x, y)
H  灯高
h  物件高度        （要求 0 < h < H）
P  物件顶点在场景中的位置
Q  投影后的影子顶点
```

影子形状 = `k · R(θ) · v`，即「物件轮廓旋转 θ 后放大 k 倍」。
**旋转不改变影子中心**（当物件重心在局部原点时）；灯位只改 k 和影子中心位置。

### 匹配

在投影板上按 `sample_resolution`（默认 128×128）均匀采样，统计 `T`（目标点数）、
`S`（影子点数）、交集，得到 `precision` 与 `recall`。

采用**交叉宽容**的边缘容差 `t`（单位：采样像素）：

```
precision = |S ∩ (T ⊕ t)| / |S|      分子用放宽后的目标
recall    = |(S ⊕ t) ∩ T| / |T|      分子用放宽后的影子
```

> 两边一起放宽是无效的——分子分母同比变化，比例几乎不动。必须交叉。

### 吸附

松手时，若物件与 `golden_solution` 的距离在 `snap_distance`（桌面像素，默认 8）以内，
且**灯位一致、角度差 < 1°**，则吸附到解位。逐物件独立判断，只吸接近的那一个。

### 星级

| 星级 | 条件 |
|---|---|
| ★★★ | P ≥ 0.97 且 R ≥ 0.97 且 步数 ≤ par |
| ★★☆ | P ≥ 0.94 且 R ≥ 0.95 且 步数 ≤ par + 2 |
| ★☆☆ | 达到通关阈值 |

因为吸附会把位置精确对齐（P = R = 1.0），三星实际主要由**步数**决定。

## 关卡数据结构

每关一个 `data/levels/LXX.json`：

```jsonc
{
  "level_id": "L01",
  "chapter_id": "CH01",
  "title": "第一盏影子",
  "description": "一句话委托",

  "board": { "width": 1.0, "height": 1.0, "sample_resolution": 128 },

  "light_presets": [
    { "id": "center", "position": [0.50, 0.15], "height": 3.0 }
  ],
  "active_light_preset": "center",
  "light_moves_count": true,        // 切换灯位是否计入步数

  // 目标区域，可给多个多边形（判定取并集）
  "target_shapes": [ [[0.26,0.906],[0.50,0.906],[0.38,0.714]] ],

  "objects": [
    {
      "id": "triangle_01",
      "shape": [[-0.10,0.08],[0.10,0.08],[0.00,-0.08]],  // 局部轮廓，相对物件自身原点
      "height": 0.5,
      "position": [0.66, 0.42],
      "rotation_deg": 0,
      "movable": true,
      "rotatable": false
    }
  ],

  "par_moves": 1,

  // 用于吸附与回归测试，必须是真实可通过的解
  "golden_solution": {
    "light_preset": "center",
    "objects": [ { "id": "triangle_01", "position": [0.40, 0.70], "rotation_deg": 0 } ]
  },

  "win_threshold": {
    "precision": 0.90,
    "recall": 0.92,
    "edge_tolerance": 4.5,          // 采样像素；0 表示关闭
    "snap_distance": 8.0            // 桌面像素；0 表示关闭
  },

  "hints": ["提示一", "提示二"]
}
```

### 做新关卡时的坑（都踩过）

- **`golden_solution` 必须是精确解。** `tests/run_level_checks.gd` 会拿它跑阈值，不通过就报错。
- **物件 `position` 同时也是它影子的参考坐标**：`影子中心 = L + k·(position − L)`。
  已知想要的影子中心，反解位置用 `position = L + (目标中心 − L) / k`。
- **多个物件拼同一图形时，shape 的原点要设在各自的特征点上。** 都用几何中心会导致反解出的
  物件位置重合，在桌面上叠成一团，没法分别拖。
- **用来卡条件的物件要占目标面积 40% 以上。** 否则它摆错了会被其他正确物件稀释，
  判定余量不足（0.91 vs 阈值 0.92 这种，改个参数就漏）。
- **目标间距要按「桌面上点得开」反推**，不能只按视觉美观排：影子间距 = 物件间距 × k。
- **考旋转方向的关卡，形状必须关于所有轴都不对称。** 等腰三角形转 +30° 和 −30° 是镜像，
  重叠一大半，会漏判。矩形有 180° 对称，同样要小心。

## 导出 Android

环境要求：JDK 17、Android SDK（build-tools 34+、platform 34+）、Godot 导出模板。

```bash
godot --headless --path . --export-debug "Android" build/shadow-workshop.apk
adb install -r build/shadow-workshop.apk
```

配置见 `export_presets.cfg`：包名 `com.sangyan.shadowworkshop`，仅 `arm64-v8a`，
使用预编译模板打包（`use_gradle_build=false`，不需要 Gradle 和 Android Studio）。

> 修改 EditorSettings 里的 `android_sdk_path` 时，要先关掉 Godot，否则退出时会被内存中的值覆盖。
